# Instagram strategy branch

Read the V4 platform rules, recent patterns, source manifest, and sidecar. Refresh official rules if the review is older than 30 days or the interface changed.

Read the production Skill's [approved caption system](../instagram-production-v4/references/approved-caption-system.md) when defining `caption_direction`.

Complete `creative-brief.json` for one 1080×1350 `concept_single` image using [the shared three-platform visual system](../textile-social-controller-v4/references/approved-visual-system.md). Require a complete finished-furniture hero, original composition, furnished foreground/middle/background depth, directional light and shadow, restrained verified typography, and material-faithful texture scale. The image must be generated independently for Instagram. Select one caption mode—product editorial, human-use tension, or material design—based on the source and concept. Specify one concrete CTA rather than requiring a question. Cite observed public samples without treating visible reactions as reach or conversion.

Do not generate images or publish.
