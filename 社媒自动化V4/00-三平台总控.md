# 三平台获客内容系统 V4｜便携测试版

核心顺序：先读取有来源的原材料，再研究当前平台，之后按平台原生尺寸独立生成，最后进入审核式发布。禁止先做一张通用图再裁成三个平台尺寸。

## 分项

每个平台有四个互不混用的分项：

1. 原材料读取：核对源文件、来源说明与 SHA-256。
2. 规则与策略：检查平台规则、近期公开样本、受众、目标、画布和文案方向。
3. 原生图文生产：分别生成平台尺寸图片、文案、用量清单并校验。
4. 发布与复盘：只读取一个已经校验的待发布包，停在最终公开按钮前等待授权。

分项只通过结构化文件交接：`source-manifest.json` → `creative-brief.json` → 平台成品包 → `publish-ready/<platform>/<run_id>/` → `publish-result.json`。

## 三平台画布

| 平台 | 画布 | 主要目标 |
|---|---:|---|
| Instagram | 1080×1350 | 停留、收藏、私信询盘 |
| Facebook | 1200×1500 | 评论、分享、社群信任 |
| LinkedIn | 1080×1350 | 专业信任、B2B 线索 |

共享视觉标准，但最终图片和文案都必须分别生成，不得跨平台互用。

## 浏览器与发布边界

所有网页操作使用 Safari。账号登录、验证码和安全挑战由使用者本人处理。自动化可以完成上传、填文案、披露设置和最终预览；最后使内容公开的 `Share` / `Post` / `Publish` 必须逐平台获得人工确认。

按钮点击不等于成功。只有永久链接可打开、可见账号正确并确认没有重复发布时，才记录 `published_verified`。

## 内容与事实边界

- 默认交付 `concept_single`：每个平台一张完整成品家具概念图。
- 画面要有前景、中景、背景、方向性日光、真实阴影与景深；避免死白、塑料感和空旷样板间。
- 保持源材质的颜色、图案轮廓、纹理单元、绒向、压花、光泽与真实比例。
- 不虚构成分、认证、性能、价格、库存、MOQ、交期、产能、客户案例或量产状态。
- 概念图必须披露 AI/合成属性；真实产品图只有在文件哈希与源图完全一致时才可视为未生成。
- 项目没有微信、邮件或其他消息发送功能。
