# 纺织三平台社媒自动化｜教师测试版

适用于 macOS + Codex + Safari 的 Instagram、Facebook、LinkedIn 三平台测试包。

## 下载

[下载 v1.0.0 教师测试包](./textile-social-automation-starter-v1.0.0.zip)

下载后解压，在终端进入项目目录并运行：

```bash
python3 setup_teacher.py
```

安装器会在桌面创建“纺织社媒自动化”文件夹，并从 Hysure 官网下载第01批20个原素材。三平台分别生成原生尺寸内容，最终公开发布前必须人工确认。

完整说明、13个分项 Skill、脚本和隐私边界都包含在 ZIP 内。仓库不包含账号密码、Cookie、历史发布或私人素材。
